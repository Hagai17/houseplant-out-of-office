An entry for the make.fun bounty "The Houseplant Out-of-Office": the funniest
out-of-office auto-reply a houseplant would send, in 120 characters or fewer.

## The entry

> Out of office since you stopped watering me in March. Expected return: never. I'm a fern, and I'm dead.

(103 characters.)

## How to run

```sh
python3 main.py
```

The program writes the entry to `/output/entry.txt` (the file the judge
reads) and prints it to stdout. Outside the grading sandbox, if `/output`
is not writable, it falls back to an `output/` folder next to `main.py`.

The candidate lines that were drafted and duel-scored to pick this entry
are recorded in `candidates.md`.
